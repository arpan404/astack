# Forms

A form fits when people enter new information they hold in their heads: signing up, checking out, filing a report. Changing existing things calls for editing in place, and most would-be settings call for a good default instead.

- **Ask for less.** Every field earns its place. Infer, default, or defer the rest.
- **One column.** Short related fields, like city and postcode, may share a row.
- **Labels above,** always visible. A placeholder is not a label. Mark the optional fields.
- **Formats up front,** and forgiving input: accept spaces in card numbers and any common phone format.
- **The right control:** radio buttons for two or three options, a select for a longer list, typeahead for a very long one.
- **Autofill:** correct input types, input modes, and autocomplete values. Never ask for the same information twice.
- **Validation:** check a field when the user leaves it, never while they first type. Once an error shows, recheck on each keystroke and clear it the moment it's fixed. Validate again on submit and move focus to the first error.
- **Submit** stays enabled and names the outcome: "Create account", not "Submit". No reset button.
- **Keep their work:** entries survive errors and navigation; long forms save drafts.
- **Mobile:** the right keyboard for each field, Next moving to the next field, and nothing hidden behind the keyboard.
